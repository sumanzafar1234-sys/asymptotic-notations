Chaining

Multiple keys that map to the same bucket are grouped in a chain.

Open addressing

If a slot is occupied, probe another slot according to a rule such as linear probing.

Static vs dynamic hashing

Static hashing

Uses a fixed basic bucket structure; overflow may need extra handling.

Dynamic hashing

Can split or expand buckets as data grows. Extendible hashing is one example.
