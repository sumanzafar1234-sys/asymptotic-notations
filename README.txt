DBMS INTERACTIVE LAB
====================

HOW TO RUN
1. Extract DBMS_Interactive_Lab.zip to a folder.
2. Open the extracted folder.
3. Double-click index.html.
4. It opens in Chrome, Edge, Firefox, or another modern browser.
5. Use the left navigation to open File Organization, Indexing & Trees,
   Hashing Playground, and Quiz Center.

NO INSTALLATION REQUIRED
This is a front-end educational demo made with HTML, CSS, and JavaScript.
Internet is only used for optional Google Fonts; the app itself works locally.

MODULES
- File Organization: Heap, Ordered, Hash-based record views; add and search records.
- Indexing & Trees: Dense/Sparse and Primary/Secondary examples; conceptual B-Tree/B+ Tree search.
- Hashing Playground: h(k) = k mod 10, Chaining and Open Addressing (linear probing).
- Quiz Center: 10 practice MCQs with instant explanations and score.

NOTES
This is an educational simulator, not a production DBMS. Tree diagrams are
simplified teaching illustrations. Real DBMS implementation details can vary.
